# Nativo Sabe

Guia local de Cajueiro da Praia, Piauí: praias, comida, passeios e comércio local.

## Tecnologias

- React 19
- TypeScript 7
- Vite 8
- Lucide React (ícones)
- Oxlint

## Como rodar

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

## Estrutura

- `src/App.tsx` — página principal, categorias, busca e filtros
- `src/App.css` — estilos e responsividade
- `public/imagens/` — logos e foto do herói

## Estado atual

Site estático com dados de exemplo. Busca e filtros funcionam localmente.
